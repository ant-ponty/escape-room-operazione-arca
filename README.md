# 🕵️ OPERAZIONE ARCA — Escape Room per Agenti Speciali

**Agenti:** Miriam (12) e Laura (9)
**Durata stimata:** 70-85 minuti
**Game Master:** papà
**Tema:** Missione segreta — recuperare il "Codice Arca", il database che protegge gli animali in via d'estinzione, rubato da un hacker.

## 📖 La Storia

L'**A.S.S.O.** (Agenzia Segreta Salvaguardia Organismi) protegge gli animali rari del mondo. Il loro archivio digitale, chiamato **ARCA**, contiene le coordinate di tutti i santuari segreti degli animali.

Un hacker misterioso, che si firma **VULTURE** (l'Avvoltoio), è riuscito a rubare l'ARCA e l'ha rinchiusa in una valigia blindata. Prima di sparire, ha lasciato una scia di scatole, lucchetti e codici — una sfida, per dimostrare che nessuno è più intelligente di lui.

L'A.S.S.O. ha convocato due nuove agenti: **Agente FALCO (Miriam)** e **Agente LINCE (Laura)**.

## 🎮 Come Usare Questo Repository

1. **Stampa i documenti** in questo ordine:
   - DOC 0 (lettera in busta)
   - DOC 1 (poster A3)
   - DOC 2A + 2B (tesserini + ordine)
   - Tutti gli altri (tagliali in A4 o A5 come indicato)

2. **Consulta la CHECKLIST** per non dimenticare nulla

3. **Leggi la GUIDA GAME MASTER** prima di iniziare

4. **Nascondi gli oggetti** seguendo NASCONDIGLI-MAPPA.md

5. **Imposta i codici** della tabella CODICI-SOLUZIONI.csv
